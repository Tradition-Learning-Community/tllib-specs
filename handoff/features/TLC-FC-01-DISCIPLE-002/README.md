# TLC-FC-01-DISCIPLE-002 — Provisionally separated definition

This package defines the autonomous declarative handoff for the Disciple definition feature.

It preserves the exact source identities, records the symbol-only Master dependency without interpreting it, and emits a deterministic definition descriptor. Missing dependency material blocks scientific execution only; it does not block descriptor construction. No public fields, aliases, types, dimensions, or concrete representation are invented.

Normative behavior is defined by `contract.json` and `acceptance.json`. Upstream evidence is enumerated in `traceability.json`.
