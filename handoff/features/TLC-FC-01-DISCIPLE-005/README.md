# TLC-FC-01-DISCIPLE-005 — Deferred equation

This package preserves the unresolved Disciple equation operation as a non-executable descriptor. It supports deterministic preparation and explicit refusal of scientific execution with `DISCIPLE_UNRESOLVED_OPERATION`.

No cited equation is evaluated, simplified, discretized, or approximated; no input, output, type, dimension, tolerance, or numerical method is invented. Normative behavior is in `contract.json` and `acceptance.json`; evidence is in `traceability.json`.
