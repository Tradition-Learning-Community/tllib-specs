# TLC-FC-01-DISCIPLE-007 — Locally blocked invariant

This package preserves the local scientific blocker and emits a deterministic blocked invariant descriptor. Scientific evaluation is refused with `DISCIPLE_UNRESOLVED_SEMANTICS`.

No invariant truth value or executable predicate is produced, and the blocker is never converted into a default. Normative behavior is in `contract.json` and `acceptance.json`; evidence is in `traceability.json`.
