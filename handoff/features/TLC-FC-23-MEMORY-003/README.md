# TLC-FC-23-MEMORY-003 — Adaptive memory operator

This package implements only the algebra that can be executed without inventing missing science. The caller supplies the already evaluated continuous-memory integral, event states, current event weights, and the values of the unresolved `delta_epsilon` factor. The implementation validates compatible event arrays, evaluates the finite source sum, and adds it to the continuous term. It must not choose a quadrature method, approximate a Dirac distribution, define `delta_epsilon`, or invent evolution rules for `w_i(t)`. Missing external terms produce structured errors.
