# TLC-FC-01-DISCIPLE-001 — Constraint admissibility

This package defines the autonomous structural handoff for the Disciple constraint-admissibility feature.

It validates the exact feature identity and preserved source-reference collections, then emits a deterministic validation descriptor. Scientific values remain opaque: the package does not decide whether any cited constraint is satisfied and does not invent types, dimensions, aliases, predicates, equations, or numerical methods.

Normative behavior is defined by `contract.json` and `acceptance.json`. Upstream evidence is enumerated in `traceability.json`.
