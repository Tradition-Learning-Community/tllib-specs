# TLC-FC-01-DISCIPLE-006 — Invariant admissibility

This package validates and preserves the exact Disciple invariant references, then emits a deterministic structural validation descriptor. It never evaluates an invariant and never asserts that an invariant is true or false.

Executable predicates, operand types, dimensions, and scientific truth values remain unresolved and opaque. Normative behavior is in `contract.json` and `acceptance.json`; evidence is in `traceability.json`.
